# Conjunctive cardinality at a fixed summary size

Use the UCI Adult source table (adult.data) with six publicly defined categorical columns: workclass, education, marital status, occupation, relationship and native country. Preserve the literal missing category. Encode each value as its zero-based index in the sorted distinct values of its column. The shared schema dictionary and row count are available to every estimator. Never release row records or predicate literals. Evaluate using exact counts on this table. Generate the external workload from adult.test using row ordinals only, retaining the upstream source splits. This is a data-derived public development benchmark; query predicates are experimental. No protected-attribute decisions are made.

Fix 32,768 serialized bytes per synopsis, excluding the common schema, cardinality and decoder. Test uniform row sampling; marginal independence; a maximum-mutual-information Chow–Liu tree with exact sum-product for unobserved fields; and the compressed sparse full six-column contingency table when it fits. For tree plus sample, allocate the remaining bytes after the tree to a fixed uniform sample. Compare two zero-aware smoothers using a prior equivalent to four sampled rows: marginal independence and the tree. Candidate uses the tree prior with 32 pseudo-observations for zero or rare matches, decaying continuously as 32/(1 + number of sampled matches). Competing fixed tree prior uses 4. Also include the candidate with constant 32, distinguishing adaptive shrinkage from changed prior strength. Serializing discrete summaries counts every literal count and edge; sample uses six uint8 per retained row. Fit models from the same full table. Compare the deterministic summary-size fallback of sorting the whole table and compressing it losslessly if it fits; it can falsify the benefit even before further learned baselines.

For each of two workloads draw 600 queries, alternating widths 3, 4 and 5. With fixed NumPy generator seed 701 choose a column subset uniformly and draw predicate values either from one external row (joint) or independent external rows (independent). Repeated queries reflect this workload distribution. For each of five seeds (11–15), select samples without replacement from the source table. Primary metric is mean absolute log-cardinality ratio with add-one correction, averaged equally across both workloads and seeds. Evaluate zero- and nonzero-count strata separately. A development advance requires at least a 5% loss reduction over every feasible baseline and a reduction on each workload. A loss ends the publication claim. No runtime superiority, independent holdout or clinical claim. If the compressed full table fits, report its result explicitly. Small sample summaries may be compressed more heavily by other encoders; count a zlib-compressed sorted uniform sample baseline as well, searching nested sample prefixes by bisection to the largest measured fit.
