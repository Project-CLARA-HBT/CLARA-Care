# Development test of shared rare values as evidence for schema matches

Use every Magellan and Wikidata pair in the Valentine ICDE 2021 archive. The creators distribute the fabricated table pairs and their link labels under CC BY 4.0. Only counts and column labels for evaluation will leave the local run. Wikidata supplies four views of one parent and therefore contributes one family to the descriptive report. Sample the first 96 records of each table in archive order and expose the same pandas frames to every arm. Preserve native type inference. No external model calls or tuning. [Dataset and contributors](https://doi.org/10.5281/zenodo.5084605) · [Authors' implementation](https://github.com/delftdata/valentine)

Compare exact normalized header, Valentine Cupid default, Valentine COMA schema only, and COMA schema plus instance values (defaults otherwise). A potential failure of bag-of-token similarity is that many columns share common field values such as flags. The candidate begins with the last comparator's predicted links and adds a link only when both columns are each other's unique best, at least three distinct shared full-cell values occur in precisely one column per side, and the number of such shared values covers at least 50% of the smaller distinct nonempty value set. Compare an otherwise identical ablation that lets shared values occur in multiple columns. Lowercase and collapse whitespace identically for both versions. Keep existing COMA links to isolate the incremental effect. Count all predicted exact source-target links; unmatched links are false positives, omitted published links are false negatives. Score per-pair F1, then the equal-pair mean separately for Magellan and Wikidata. Zero matches give zero F1 for a nonempty gold set. An exception makes that arm incomplete. Require strict improvement over every measured comparison in both groups before any further test. No iteration on this evaluation.

COMA already combines linguistic and instance evidence. The candidate tests the narrower marginal contribution of rare full-cell ownership after COMA. Cupid (VLDB 2001) is a schema-structure comparator. Magneto (PVLDB 2025) adds learned retrieval and reranking; it would be necessary for a broad publication claim. This development elimination grid cannot establish superiority to Magneto or uniqueness of rare-value evidence. [Cupid](https://www.vldb.org/conf/2001/P049.pdf) · [Magneto](https://arxiv.org/abs/2412.08194)
