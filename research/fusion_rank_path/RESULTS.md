It missed the registered 20% runtime saving against early stopping on each of the three sources. Retire the first method's performance claim. ## Reproduction

Use the score arrays generated by the [preceding retrieval experiment](../retrieval_disagreement/RESULTS.md), which records the NanoBEIR source revisions, CC BY 4.0 attribution and MiniLM encoder revision. The sparse and dense score matrix is specific to each query. From this directory, with NumPy and a C++17 compiler, use a new output directory. The recorded input text SHA-256 is `413cfac50ca48e8fd06ab3c1995002a0ec1d1d5c568daf9633a7189b8f13d600`. The timing process used the Intel Core i5-12600K exposed through WSL2. Absolute times will vary.

```bash
python inputs.py "$SCORES" "$OUT/data.txt"
g++ -O3 -std=c++17 path.cpp -o "$OUT/rankpath"
taskset -c 0 "$OUT/rankpath" "$OUT/data.txt" "$OUT/changes.tsv" "$OUT/timings.csv"
cmp "$OUT/changes.tsv" results/changes.tsv
python verify.py "$OUT/data.txt" "$OUT/changes.tsv" "$OUT/rankpath"
python summarize.py "$OUT/timings.csv"
```
