# External transport of exact fusion rank paths to full BEIR collections

This protocol precedes access by this study to the external test labels or full score arrays. We have seen NanoBEIR development results, including failures against the bounded-summary ablation. Freeze implementation c6c4a60f, candidate arm 7, all nine comparator arms, original fixed-point convention, k=10, original source-batch timing harness, seed, 12 shuffled rounds following one warmup per source. Use all published test queries present in official SciFact (300) and NFCorpus (323) qrels and the complete corpus of each. Sort IDs lexicographically as strings; exclude matching query/document IDs under the original contract and report any lost positive. Use only graded relevance >0 to identify focal documents. No query, label, feature, score, method, CPU or source selection after inspection. Failed inputs stay visible. These are corpus-specific external timing/correctness checks, not retriever efficacy tests.

Reuse the pinned all-MiniLM-L6-v2 and BM25 code and complete input preprocessing from the NanoBEIR evaluation. Verify archived encoding assets. Obtain author BEIR ZIPs with the BEIR README's MD5s or the BEIR maintainers' pinned Hugging Face data and qrels. Record content digests, publication and dataset rights. Keep raw text external. Report any overlap with each development collection using NFC-normalized casefolded, whitespace-collapsed full query text and title+body (also body separately). Include cross-field matches and empty strings separately; fingerprint similarity can miss paraphrases. No removal based on these diagnostics.

Run single CPU-affined benchmark on WSL2 after score generation on its RTX 4060 Ti. Include preprocessing from the common input in timings as before. For each source and comparator use median within-round fractional time saved, wins/ties/losses and the 12 observed values. Report descriptive 2nd-to-11th order statistic intervals for the median (99.37% nominal for independent continuous rounds; shared-host rounds can be dependent). The 20% per-source margin and all-arms gate are unchanged. Any failure remains an external failure; passing here cannot undo the failed development gate. Verify every returned curve independently at all 65,536 weights and stable full sort at the nine frozen weights. Preserve positive counts, excluded qrels, method hashes and round positions. Score classification, clinical questions and scientific superiority of retrievers are outside this endpoint.
