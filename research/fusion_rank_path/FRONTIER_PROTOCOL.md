# Saturating counts of directional rank changes

This follow-up uses the three previously seen NanoBEIR development sources. The first clipping method missed the 20% margin versus early stopping. We will examine a smaller exact representation and compare it with an equally optimized ablation. Positive labels identify the documents whose ranks are audited. They cannot select the algorithm per query.

For a fixed positive, sort the first weights at which a rising rival overtakes it. Only the first k such weights can affect its clipped rank. For falling rivals retain the last k weights at which each stops outranking it. For every weight, saturating each count separately at k before summing preserves the rank clipped at k+1. A bounded summary of at most 2k crossings per positive suffices. Maintain these extrema in a single pass; test if a partial prefix already excludes all weights. Each rival is affine, making the endpoint comparison exact even for ties when ID order is included. This work studies whether that representation adds measurable benefit under shared low-level optimizations. Novelty relative to reverse top-k literature is open. [Literature audit](PRIOR.md)

Use the same exact data, tie order, outputs, warmup, shuffled matched 12-round timing, 20% per-source median saving and independent oracle as the first protocol. Include all five first-round arms; include a block-oriented optimistic early sweep that uses the same input and scan as the candidate, and a bounded-summary arm without prefix infeasibility. Report throughput losses even for a retained development method. Implement the new scan in groups of eight, packing the two 16-bit endpoints in separate native 32-bit vectors when needed; include building any extra data layout in each timed query. Use AVX2 for both the optimized sweep and the extrema candidates; original arms receive the same compiler flags. The prefix infeasibility check is made after each group that has changed the bounded summary. Require the complete candidate to clear the margin against each baseline including both new ablations. A miss on any registered comparator retires that performance claim.
