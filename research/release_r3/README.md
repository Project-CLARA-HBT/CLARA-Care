# R3 Evidence Release Preflight

This directory is generated by `synchronize_r3.py` for R3 §2.11. It audits the
tracked manuscript claim ledgers, records the canonical GLHS wording, keeps the
64-subject positive and 384-subject descriptive synthetic records separate, and
reads (without changing) the agent-A publication registry for GovRed/GovMut venue
overlap.

## Run

```bash
python3 research/release_r3/synchronize_r3.py
```

The script is deterministic for a fixed repository tree and source commit. It
writes `BUILD_INFO.json`, `EVIDENCE_MANIFEST.json`, `SHA256SUMS.txt`, and a
`package/` tree containing only explicitly selected tracked research
manuscript/ledger/status sources and any tracked PDFs. It never copies untracked
user manuscripts, sealed artifacts, evaluation files, or `publication_registry.yaml`.

## PDF/build preflight

This checkout has no tracked PDF source according to `git ls-files '*.pdf'` at
package-generation time. The preflight therefore reports missing PDF sources;
an untracked PDF is intentionally not packaged. The script also reports the
availability of `latexmk`, `pdflatex`, `xelatex`, and `pandoc`; no source PDF is
claimed when the corresponding build tool is absent.

- The 64-subject positive cohort is `COMPLETE_VALID`; the 384-subject record is

Exit status `2` means the package was generated but at least one manual or
evidence gate remains open. This is expected for the current R3 state and is not
converted into a pass by the release metadata.
