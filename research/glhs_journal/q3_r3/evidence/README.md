# GLHS R3 Evidence Repository

This directory contains claim-to-evidence mappings, verification summaries, and audit ledgers for the GLHS R3 campaign.

## Directory Organization
- `claim_to_evidence.csv`: Direct matrix mapping manuscript claims to experiment IDs and artifact digests.
- `EVIDENCE_STATUS_REPORT.md`: Continuous verification report assessing claim eligibility.
- `audit_traces/`: Trace logs and third-party audit verification summaries.
