# Multi-support development protocol

Reuse the parent MovieLens 25M cohort, verified archive and transaction construction. One request returns three materialized canonical JSON byte strings for supports 500, 1000 and 1500. Compare three implementations using pyfim 6.28. Independent mines each support after one shared build. Filter mines once at 500, sorts once, filters by count and uses the standard JSON encoder. Stream encodes each sorted record once and appends it to the qualifying output buffers. Each method must reproduce all three previously recorded SHA-256 values. Closedness depends only on equal-support supersets, so raising the frequency cutoff preserves closedness for every surviving set.

Rotate method order over six blocks (all six permutations), each method in a fresh process, on the same host. Time from before opening the ZIP through three completed byte strings, excluding interpreter startup, checksum verification and output validation. Report median totals, phase times, RSS, paired savings against the faster baseline (independent or filter), and a 20% median time-saving development target for stream. Record individual runs.
