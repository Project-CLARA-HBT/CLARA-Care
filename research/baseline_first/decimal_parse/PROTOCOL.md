# Development screen for short fixed-scale decimal fields

Select the earliest 14 distinct source dates in UCI Household Power Consumption, reading the seven measurement columns in original order from each semicolon-delimited row. Include every row and every missing value. Inspection so far covers source metadata and the upstream library version only. Open Food Facts stays reserved. A day is a paired unit from one household.

Compare unmodified fast_float v8.3.3 (048df798cab53c26c9ab1a7c15585ecf6fd5ef9c), C++17 std::from_chars, guarded scalar fixed-scale decoding, and the same guard plus two-lane SIMD division. The guard recognizes exactly one to three digits before a dot and three digits after it. Recognized mantissas and 1,000 are exactly representable in binary64. Use division in round-to-nearest mode. For mixed pairs, retain the scalar fast path for each eligible member and send other tokens to fast_float. Reserve distinct sentinel words for missing and invalid. Compare binary outputs on every token with a separate exact-rational oracle. Use a delimiter scan with length writes as a profiling reference.

Time resident input through delimiter detection, conversion including fallback, and writing the output words. Preallocate the identical output buffer, exclude file I/O, oracle, checksum, and initial buffer creation. This measures resident parsing only. Use one pinned WSL CPU, five arms in rotating order for ten rounds per day, with one warmup and repeated passes to reduce timer overhead. Keep every timing and report medians within day. Do not compare synthetic serialization of CSV into JSON with the original bytes. Require zero output disagreements and a median paired saving of at least 20% against *each* parser, including the scalar ablation. Any failure stops this mechanism before independent confirmation. No threshold or workload changes after inspecting times.
