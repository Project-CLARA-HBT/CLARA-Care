# Naming migration: functional evidence-program paths

Date: 2026-08-10

The evidence program is publication-target agnostic.  Active protocol paths
therefore describe their function, not a venue, reviewer round, or manuscript
iteration:

| Previous active path | Functional path | Status |
| --- | --- | --- |
| `evaluation/glhs_q3/` | `evaluation/structural_conformance/` | active implementation |
| `evaluation/glhs_q2/` | `evaluation/archives/structural_conformance_legacy/` | immutable historical archive |
| `evaluation/comparators/` | `evaluation/comparator_studies/` | active comparator studies |
| `evaluation/independent_adjudication/` | `evaluation/clinical_adjudication/` | clinical adjudication gate |
| `evaluation/downstream_utility/` | `evaluation/clinical_utility/` | clinical utility protocol |
| `evaluation/governance_adversarial/` | unchanged | boundary adversarial protocol |
| `evaluation/fullstack_benchmark/` | unchanged | deployment benchmark |
| `evaluation/property_assurance/` | unchanged | state/property assurance |

The archived implementation bytes are not rewritten and are not used as an
active protocol import.  Existing Q2/Q3 result directories and manuscript
references remain historical evidence; they are not relabelled or treated as
new evidence.  A future benchmark-affecting change must create a new frozen
protocol version and rerun the full matrix.
