# Risk Register — Subagent A05 (Web UX)

| Risk ID | Risk Category | Severity | Likelihood | Impact Description | Path:Line Anchor | Mitigation / Remediation Action |
|---|---|---|---|---|---|---|
| **RSK-A05-001** | ML Model & Provider Disclosure | HIGH | LOW | Internal provider or model identifiers could leak into user-facing views if raw ML responses bypass sanitization regexes. | `apps/web/lib/user-facing-text.ts:42-52` | Strict adherence to `HIDDEN_REASONING_LINE_PATTERNS` and `TELEMETRY_LABEL_PATTERNS` boundary function `safeUserFacingError`. Regular property test coverage against synthetic CoT fragments. |
| **RSK-A05-002** | Telemetry Fallback Masking Outages | HIGH | MEDIUM | In `fetchSystemTelemetry`, when `/system/metrics` fails, the client falls back to synthetic metrics (`requestCount: 21500`, `errorCount: 16`, `avgLatencyMs: 24.5`). An operator might believe the system is nominal during an API outage. | `apps/web/lib/admin-system.ts:467-475` | Clearly label telemetry cards as "Offline / Cached Simulation" when `Promise.allSettled` returns rejected, rather than rendering synthetic nominal metrics silently. |
| **RSK-A05-003** | Audit Log Explorer Fallback to Seeds | HIGH | MEDIUM | When `GET /admin/audit` is unavailable or returns 404, `getAdminAuditLog` falls back to `SEED_ADMIN_AUDIT_LOGS`, displaying historical mock entries. | `apps/web/lib/admin-audit.ts:361-366` | Surface an explicit warning banner in `AdminAuditPage` indicating that live WAL audit logs could not be reached and fallback seed entries are displayed. |
| **RSK-A05-004** | Client-Only Local DDI Disagreement with Server FIDES | CRITICAL | LOW | `quick-interaction-checker` runs an instant local check using `VIETNAMESE_DRUGS_CATALOG` before `/careguard/cabinet/auto-ddi-check` completes. If the local dictionary reports "safe" but the server's FIDES gate discovers a critical DDI, a race condition or stale result could misinform the user. | `apps/web/components/medicines/quick-interaction-checker.tsx:154-177` | Ensure that server response always overrides local optimistic results immediately upon resolution, and ensure high-severity server verdicts cannot be downgraded by client cache. |
| **RSK-A05-005** | Contact Form Ticket Simulation | MEDIUM | HIGH | `ContactForm` generates a client-side ticket ID (`TKT-YYYY-XXXXXX`) via `setTimeout` without persisting to a CRM or compliance queue, giving users a false sense that a support/DPO ticket was filed. | `apps/web/app/contact/contact-form.tsx:241-258` | Connect contact submission to an authenticated backend route (e.g. `POST /api/v1/support/tickets` or `/compliance/dsar/request`) or display an explicit disclaimer that this is a demonstrator form. |
| **RSK-A05-006** | Mock Medication Course Fallback | MEDIUM | MEDIUM | Direct navigation to `/medicines/[id]` for an ID not present in API state synthesizes an active course of Metformin 500mg with DB00331. | `apps/web/app/medicines/[id]/page.tsx:97-109` | Return a 404 / "Thuốc không tồn tại" error page rather than synthesizing an arbitrary medication course when an ID is unmatched. |
| **RSK-A05-007** | Admin Route Client-Side Gating Reliance | CRITICAL | LOW | If an administrator route relies solely on `getRole() !== "admin"` client-side check, a tampered client could bypass the UI gate. | `apps/web/app/admin/overview/page.tsx:20`, `apps/web/lib/navigation.access.ts:87` | All underlying API routes (`/admin/*`, `/system/*`) strictly enforce server-side `require_roles("admin")`. The UI gate remains strictly defense-in-depth presentation control. |
| **RSK-A05-008** | Legacy Route Redirect Drift | LOW | MEDIUM | Legacy redirects in `middleware.ts` (`LEGACY_ROUTE_REDIRECTS`) and individual page `redirect()` calls must remain in sync. Any discrepancy could cause redirect loops or 404s. | `apps/web/middleware.ts:42-53` | Add an automated test that asserts all keys in `LEGACY_ROUTE_REDIRECTS` match the redirect targets in the respective page components. |
| **RSK-A05-009** | i18n Unreferenced Catalog Keys | LOW | LOW | 56 catalog keys in `catalog.ts` are currently orphaned from `lifemap.wizard` and `lifemap.timeline`, increasing bundle size. | `apps/web/scripts/check-i18n.mjs` | Prune or re-link unreferenced i18n keys during the LifeMap V2 modernization phase. |
| **RSK-A05-010** | Script Node Runner Dependency | LOW | LOW | `scripts/check-route-layout-registry.mjs` attempts dynamic import of `route-layout.registry.ts` directly via Node.js ES modules, failing unless run via `tsx`. | `apps/web/scripts/check-route-layout-registry.mjs:133` | Update `package.json` script `route-layout:check` to invoke `tsx` directly so CI/CD runs execute reliably without loader errors. |
