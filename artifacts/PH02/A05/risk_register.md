# Risk Register — Subagent A05 (Web UX)

| Risk ID | Risk Category | Severity | Likelihood | Impact Description | Path:Line Anchor | Mitigation / Remediation Action |
|---|---|---|---|---|---|---|
| **RSK-A05-021** | Path Prefix Boundary Collision | HIGH | MEDIUM | If path matching uses naive string prefix matching, an allowed path `apps/web/app/` could accidentally allow `apps/web/app_unauthorized.ts`, breaking path containment. | `scripts/ci/check_agent_path_acl.py:313-323` | Normalize paths with `posixpath.normpath` and enforce directory separator `norm_lane + "/"` matching to guarantee component-level boundary isolation. |
| **RSK-A05-022** | Cross-Agent Artifact Tampering | HIGH | LOW | A concurrent agent could write or overwrite another agent's delivery manifest or test report in `artifacts/PH02/A0X/`, corrupting the audit trail. | `scripts/ci/check_agent_path_acl.py:284-288` | Dynamic isolation rule in `get_agent_path_lanes` grants an agent access strictly to `artifacts/{phase_id}/{agent_id}/`. Modifications to any other agent's artifact directory are rejected with exit code 1. |
| **RSK-A05-023** | Directory Traversal Vulnerability | CRITICAL | LOW | A diff containing paths with `../` (e.g. `apps/web/app/../../services/api/schemas.py`) could circumvent prefix checks. | `scripts/ci/check_agent_path_acl.py:302-306` | Explicitly normalize all paths and reject any path starting with `../` or resolving outside repository root. |
| **RSK-A05-024** | Disconnected `PHASE_TASKS.json` in Container CI | MEDIUM | MEDIUM | In isolated test runners or stripped Docker build contexts, `machine/PHASE_TASKS.json` might not be mounted, causing ACL lookup failures. | `scripts/ci/check_agent_path_acl.py:35-85, 276-281` | Provide built-in fallback table for canonical agent roles across phases and support `--path-lane` CLI overrides. |
| **RSK-A05-025** | Unshared Common File Collisions (e.g. `package.json`) | MEDIUM | HIGH | Subagents needing to add dependencies might modify root-level configuration files outside their assigned lane, failing CI gates. | `templates/AGENT_TASK_PROMPT.md:11` | Strict ACL gate halts unauthorized modifications and requires subagents to submit `DEPENDENCY_REQUEST.md` to root integrator instead of editing shared configs directly. |
