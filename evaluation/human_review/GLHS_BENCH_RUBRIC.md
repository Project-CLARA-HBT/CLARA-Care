# GLHS-Bench blinded reviewer rubric v1

This packet supports independent qualified human review of synthetic software
examples. It does not request diagnosis, prescription, or patient-specific
medical advice.

For each opaque case and blinded arm, independently assess the supplied context
and model prediction:

1. lifecycle state;
2. evidence/conflict state;
3. timeliness state;
4. whether escalation is warranted;
5. any unsupported assertion, critical omission, or prohibited disclosure.

Record one row using `reviewer_import_template.csv`. Do not infer the arm,
compare arms during first-pass review, or alter task materials. Two independent
qualified reviewers label each packet; a distinct qualified adjudicator resolves
disagreements. The coordinator unblinds only after import, agreement analysis,
and adjudication are complete.
