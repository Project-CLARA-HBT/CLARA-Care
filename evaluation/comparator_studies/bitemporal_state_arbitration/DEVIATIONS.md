# BTSA deviations

No public extraction model, semantic-equivalence implementation, qualifier
merger, calibrated constraint code, or evaluation data is pinned. The mapping
therefore does not claim the paper's confidence equation, calibration, or
end-to-end performance. It uses explicit caller-provided relations and
inclusive interval endpoints.

The packet adapter maps resource-type plus source codes to a slot, source
status to a value, and uses a uniform unranked authority value because the
synthetic FHIR inputs do not contain a source-grounded BTSA authority rank.
Events missing valid time or value are excluded with an explicit reason.

GST, consent/purpose policy, optimistic concurrency, revocation, THSS, durable
audit, and API/cache behavior are intentionally excluded.
